# 🤖 Computing Historian703

> An AI-powered computing history assistant built as part of **Microsoft AI Skills Fest** while completing the **Develop Your First Agent with Microsoft Foundry** learning path.

Computing Historian703 is an AI agent designed to answer questions about the **history of computing, influential pioneers, vintage computers, artificial intelligence, and major milestones in computer science**.

The project provided hands-on experience with building and integrating AI agents using **Microsoft Foundry, Azure AI, Python, Visual Studio Code, and the OpenAI Responses API**.

---

## 🚀 Project Overview

As part of the **Microsoft AI Skills Fest**, I completed the *Develop Your First Agent with Microsoft Foundry* learning path and built a practical AI agent focused on computing history.

The project demonstrates how modern AI applications combine:

* 🤖 Foundation models
* 🧠 Agent instructions
* 🔎 Web search capabilities
* 🔌 APIs
* 🐍 Python applications
* 🛠️ Developer tools
* 🚀 GitHub Copilot
* ☁️ Microsoft Foundry and Azure AI

The goal was not only to interact with an AI model, but to understand how different components work together to create a useful **agentic application**.

---

## 🎯 What the Agent Can Do

**Computing Historian703** can help answer questions about:

* 💻 History of computing
* 👨‍💻 Computing pioneers
* 🖥️ Vintage and early computers
* 🧮 Important computing inventions
* 🤖 Artificial intelligence milestones
* 🧠 Computer science history
* 🌐 Major developments in technology
* 📅 Historical computing events

Example questions:

```text
Who invented the World Wide Web?

What was the ENIAC?

Who was Alan Turing?

When was the first computer created?

What were some major milestones in the history of AI?

How did early computers differ from modern computers?
```

# 🎓 What I Learned

One of my biggest takeaways from this project was that building an effective AI solution is **not simply about selecting a powerful model**.

A useful agentic application requires combining multiple components:

```text
Model
  +
Instructions
  +
Tools
  +
APIs
  +
Application Logic
  +
User Experience
  =
Useful AI Application
```

This project helped me understand the practical workflow involved in moving from an AI model to an **interactive, tool-enabled AI agent**.
